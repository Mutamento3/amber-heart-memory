# 用 Kelivo 接入 Amber Heart

[English](kelivo.en.md)

管理网页“设置 → 访问钥匙”里有同样的接入指南，接口地址和钥匙已经填好，点复制就行。下面的 `memory.你的域名` 换成你自己的地址，访问钥匙在“设置 → 访问钥匙”里生成、复制。

## 一、添加供应商

1. 打开 设置 → 供应商，点右上角添加供应商，类型选 OpenAI。
2. 名称：琥珀之心（也可以自己起）。
3. API Key：填琥珀之心的访问钥匙。你在 DeepSeek、Gemini 这些模型申请的 API Key，安装琥珀之心时已经填过了，不要再填到 Kelivo 里。
4. API 地址：`https://memory.你的域名/v1`。API 路径保持默认的 `/chat/completions`，Response API 保持关闭。
5. 保存后获取模型列表，把要用的聊天模型添加进来。

## 二、新建助手

1. 新建一个助手，进入助手页。
2. 基础设置：上下文消息数量设为 4（不要关闭，关闭就是无限制，聊久了请求会越来越大，可能报错）。
3. 提示词：琥珀之心填了人设的话，这里的系统提示词不会生效，可以留空；“追加当前时间”不用开，琥珀之心每轮会自己带上当前时间。
4. 记忆：“使用长期记忆”和“允许回忆过去对话”都关掉。关掉以后，Kelivo 自己的记忆和对话摘要都不会运行，设置里的“记忆”和默认模型里的“摘要模型”就不用管了。
5. 聊天时点顶部标题下面的模型名，选琥珀之心下面的模型。

其他设置保持默认就行。

## 三、接上 MCP（让 TA 能自己查记忆、记书签）

1. 打开 设置 → MCP，点右上角的 +。
2. 是否启用：打开；名称：琥珀之心；传输类型：HTTP。
3. 服务器地址：`https://memory.你的域名/mcp`。
4. 自定义请求头：点“添加请求头”，请求头名称填 `Authorization`，请求头值填 `Bearer 访问钥匙`（Bearer 后面空一格）。
5. 点保存，Kelivo 会自动连接。
6. 回到聊天界面，点输入框下面左数第四个图标（工具箱样子），在“工具”里打开琥珀之心。

## 四、小功能（设置 → 默认模型）

- 聊天建议模型：保持未启用。开了的话，生成建议的请求会被当成聊天记进记忆。
- 翻译模型：不要选琥珀之心下面的模型。没单独设置的话，翻译会用当前聊天的模型，也就是走琥珀之心，翻译的内容会被当成聊天记下来。

## 注意

- Kelivo 里只填琥珀之心的访问钥匙。模型的 API Key 只在安装琥珀之心时填，不要直接填进 Kelivo，否则聊天会绕过琥珀之心，既记不下来，也召回不了记忆。
- Kelivo 自带的记忆、对话摘要都要关掉，记忆交给琥珀之心。
- 琥珀之心填了人设，会替换 Kelivo 里的系统提示词、角色卡和世界书。
- 在 Kelivo 里开新对话，琥珀之心记下的聊天不会清空，TA 仍记得最近聊过的内容。想让 TA 忘掉某几轮，到琥珀之心管理网页的“召回”页点右上角的“删除”，勾选后删掉。

## 连不上怎么办

- 提示 401：访问钥匙没复制全，或者已经作废，回管理网页重新复制。
- 提示 404：接口地址填错了，照上面的格式重新填。
- 拉不到模型：先用浏览器打开 `https://memory.你的域名`，看能不能出现登录页。打不开说明服务或证书有问题，见 README 的安装检查方法。
- 能聊天，但“召回”页没有记录：这个对话用的多半不是琥珀之心下面的模型。
