# 用 Operit 接入 Amber Heart

[English](operit.en.md)

管理网页“设置 → 访问钥匙”里有同样的接入指南，接口地址和钥匙已经填好，点复制就行。下面的 `memory.你的域名` 换成你自己的地址，访问钥匙在“设置 → 访问钥匙”里生成、复制。

## 一、配置模型

1. 打开 设置 → 模型与参数配置（第一次打开 Operit 时，首屏点“配置其他模型”也会进到这里），保持“默认配置”。
2. API提供商：选“OpenAI通用”（在“通用兼容”分组里）。
3. API端点：`https://memory.你的域名/v1`。
4. API密钥：填琥珀之心的访问钥匙。你在 DeepSeek、Gemini 这些模型申请的 API Key，安装琥珀之心时已经填过了，不要再填到 Operit 里。
5. 模型名称：点右边的列表图标获取模型列表，选要用的聊天模型。
6. 模型支持识图：你选的模型能看图就打开；模型支持ToolCall：保持打开。
7. 往下翻到“总结设置”，关掉“启用对话总结”。上下文设置保持默认，对话总结关了它就不会再压缩上下文。

其他设置保持默认就行。

## 二、关掉 Operit 自带的记忆

1. 回到聊天界面，点输入框下面、加号左边的调节图标（三条横线，每条上有一个小竖杠），展开“记忆”，关掉“自动保存记忆”。开着的话，Operit 每聊一轮都会再调一次模型整理它自己的记忆，这些请求会被当成聊天记进琥珀之心。
2. 同一个面板里展开“工具”，点“工具管理”，关掉 `query_memory` 和 `get_memory_by_title`。这两个是 Operit 自带记忆的工具，关掉后 TA 想查记忆就会用琥珀之心。

## 三、接上 MCP（让 TA 能自己查记忆、记书签）

1. 点左上角的菜单 → 包管理，顶部切到 MCP，点右下角的 +。
2. 在弹窗里左滑，选“远程”。
3. 主机地址：`https://memory.你的域名/mcp`。
4. 连接类型：保持 httpStream。
5. Bearer Token：只填访问钥匙本身，不用写 Bearer，Operit 会自己加。
6. 插件名称：`amber_heart`。
7. 点连接。之后 TA 需要时会自己激活琥珀之心，聊天界面里不用另外打开。
8. 打开 设置 → 工具权限设置，点“允许”右边的 +，勾上“琥珀之心:memory”和“琥珀之心:mark_moment”，点完成。这样 TA 查记忆、记书签不用每次等你批准。

## 四、小功能

- Operit 的翻译默认用“默认配置”，也就是走琥珀之心，翻译的内容会被当成聊天记下来。要用翻译的话，在 设置 → 功能模型配置 里给翻译换一个配置。

## 注意

- Operit 里只填琥珀之心的访问钥匙。模型的 API Key 只在安装琥珀之心时填，不要直接填进 Operit，否则聊天会绕过琥珀之心，既记不下来，也召回不了记忆。
- Operit 自带的记忆、对话总结都要关掉，记忆交给琥珀之心。
- 琥珀之心填了人设，会替换 Operit 里的系统提示词和角色卡。
- 在 Operit 里开新对话，琥珀之心记下的聊天不会清空，TA 仍记得最近聊过的内容。想让 TA 忘掉某几轮，到琥珀之心管理网页的“记录”页点右上角的“删除”，勾选后删掉。

## 连不上怎么办

- 提示 401：访问钥匙没复制全，或者已经作废，回管理网页重新复制。
- 提示 404：接口地址填错了，照上面的格式重新填。
- 拉不到模型：先用浏览器打开 `https://memory.你的域名`，看能不能出现登录页。打不开说明服务或证书有问题，见 README 的安装检查方法。
- 能聊天，但“记录”页没有记录：这个对话用的多半不是琥珀之心这个配置。
