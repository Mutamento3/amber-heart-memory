# Import ChatGPT chats

[简体中文](chatgpt.md)

1. On the ChatGPT website, open **Settings → Data controls → Export data**.
2. Wait for the email and download the archive.
3. In the Amber Heart admin web app, go to **Settings → Import → Go to import** (设置 → 导入记忆 → 去导入), choose **ChatGPT**, and select the entire export ZIP.
4. The preview lists all conversations, all selected by default. Uncheck the ones unrelated to the two of you (such as work Q&A), then confirm the import.

The page selects the needed files on your device before uploading. If it cannot filter the archive, it uploads the original ZIP. The upload limit of 90 MiB applies to the data actually sent.
