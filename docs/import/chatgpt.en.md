# Import ChatGPT chats

[简体中文](chatgpt.md)

1. On the ChatGPT website, open **Settings → Data controls → Export data**.
2. Wait for the email and download the archive.
3. In the Amber Heart admin web app, go to **Settings → Import → Go to import** (设置 → 导入记忆 → 去导入), choose **ChatGPT**, and upload the `conversations.json` from the archive. Newer exports may be split into several files such as `conversations-000.json`; upload them together.
4. The preview lists all conversations, all selected by default. Uncheck the ones unrelated to the two of you (such as work Q&A), then confirm the import.

**Don't upload the whole export archive**, which may contain images; upload only the JSON files. An uploaded file can be at most 90 MB; if a JSON file is larger, compress it alone into a zip and upload that (text compresses very well).
