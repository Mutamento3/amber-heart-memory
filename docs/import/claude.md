# 导入 Claude 聊天记录

[English](claude.en.md)

1. 在 Claude 网页版打开**设置 → Privacy → Export data**。
2. 等邮件，下载里面的压缩包。
3. 打开 Amber Heart 管理网页，进入**设置 → 导入记忆 → 去导入**，选择 **Claude**，上传压缩包里的 `conversations.json`。
4. 预览里会列出全部对话，默认全选。把和你们无关的（比如工作上的问答）取消勾选，再点**确认导入**。

上传的文件不超过 90 MB；JSON 超过 90 MB 时，把它单独压缩成 zip 再上传（文字压缩率很高）。
