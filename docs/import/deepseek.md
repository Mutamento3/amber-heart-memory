# 导入 DeepSeek 聊天记录

[English](deepseek.en.md)

1. 打开 [DeepSeek 网页版](https://chat.deepseek.com)，点头像，进入**设置 → 数据管理 → 导出所有历史对话**。
2. 导出完成后，使用 DeepSeek 提供的链接下载 ZIP。下载链接 7 天内有效。
3. 打开 Amber Heart 管理网页，进入**设置 → 导入记忆 → 去导入**，选择 **DeepSeek**，上传整个 ZIP。
4. 预览按对话列出记录，默认全选。取消勾选不想导入的对话，再点**确认导入**。

支持官方 ZIP 导出，不限导出格式的版本号，能读懂内容就能导入。每个对话只导入当前分支的聊天文字，跳过账号信息、思考、搜索过程、图片和其他附件。

网页会先在本机筛选所需文件，再上传。无法筛选时按原包上传。实际上传内容的上限为 90 MiB。
