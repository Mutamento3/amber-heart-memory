# 导入 Kelivo 聊天记录和记忆

[English](kelivo.en.md)

1. 在 Kelivo 打开**设置 → 数据备份**，进入**备份与恢复**页面。
2. 点**备份与导入内容 → 取消全选**，只打开**聊天记录**和**助手**。想导入记忆时再打开**记忆**。保持**文件**关闭，然后点**保存**。
3. 如果开过备份加密，先把它关掉。在**本地备份**里点**导出为文件**，保存生成的 `.zip`。
4. 打开 Amber Heart 管理网页，进入**设置 → 导入记忆 → 去导入**。选择 **Kelivo**，直接选择整个导出 ZIP，然后点**上传并预览**。
5. 在预览里勾选属于当前记忆空间的助手或对话，并选择聊天日期范围。同一个角色分在多个助手里时，可以同时勾选这些组。想导入记忆时，在 **Kelivo 记忆**下面展开分组，逐条核对再点**确认导入**。全局记忆里可能混着多个助手的条目，可以单独勾选或取消。

**备份与导入内容**同时影响本地、WebDAV 和 S3 备份。导出后请回到这里点**全选**再**保存**，否则之后的备份也会缺少刚才关掉的类别。

接入 Amber Heart 之后的聊天已经记录过了，导入时把结束日期选在接入之前。

备份里找不到助手名称时，可以用「助手 1」「助手 2」旁的对话标题辨认。没有关联助手的对话会列在「未归属」组。

聊天还在的话导聊天就够了，聊天删掉的可以用记忆补回来。新版中由工具写入或自动提取的记忆，按琥珀之心的安装时区使用条目创建日期。手动添加、提炼生成及旧版的记忆，导入时日期为未注明。

聊天导入读取用户和 AI 的文字消息，每组优先取 Kelivo 选中的版本。要导入旧版 `chats.json` 里的聊天，请先升级 Kelivo 再重新备份。

网页会先在本机筛选所需文件，再上传。无法筛选时按原包上传。实际上传内容的上限为 90 MiB。
