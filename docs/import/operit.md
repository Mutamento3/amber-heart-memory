# 导入 Operit 聊天记录和记忆

[English](operit.en.md)

1. 在 Operit 打开**设置 → 数据备份与恢复**。
2. 导入聊天时，进入**聊天记录**，选择**导出 JSON**。导入记忆时，在同一页面进入**记忆库**，选择**导出**。两种导出会各生成一个文件。
3. 打开琥珀之心管理网页，进入**设置 → 导入记忆 → 去导入**，选 **Operit**。可以上传单个 JSON、同时选择聊天和记忆的两个 JSON，或上传包含导出文件的 ZIP。点击**上传并预览**。
4. 按角色卡或对话勾选要导入的聊天，并选择聊天日期范围。想导入记忆时，在 **Operit 记忆**下展开列表，勾选所需条目，再点**确认导入**。记忆条目默认不勾选，聊天日期范围只用于筛选聊天。

接入琥珀之心之后的聊天已经记录过了，导入时把结束日期选在接入之前。

聊天导入使用 Operit 界面选中的回复版本，保留用户和 AI 的正文，跳过总结、思考和工具内容。图片和其他文件以占位文字显示。导出里的分支与群聊按普通对话处理。

记忆库只导入纯文本条目，标题和正文会一起交给模型整理。通过记忆分析自动生成的条目按安装时区取创建日期，其余来源的日期为未注明。

浏览器会先从 ZIP 中筛出 JSON。无法筛选时会上传原包。实际上传内容的上限为 90 MiB。
