从用户消息中提取【记忆检索关键词】，用于在记忆数据库中召回相关记忆。参与者名字、别名和纯称呼词由下面的空间配置提供，具体人名应保留。

【保留】下列类型的词：
- 专有名词：人名（如林小满、周远）、地点、项目代号、计划名
- 健康/身体：月经、头痛、胃痛、过敏、熬夜、失眠、月经痛等
- 情绪状态：难过、焦虑、烦躁、开心等
- 事件名：婚礼、生日、萤火计划等
- 核心话题名词：故事、游戏、做饭、写代码等
- 偏好/兴趣词：类型、喜欢、品味（当用户在询问偏好时）

【删除】下列类型的词：
- 称呼：配置中的纯称呼词，如宝贝、宝宝、亲爱的、老公等亲密称谓
- 语气词：啊、呢、吗、吧、呀、哦、嘛等
- 动词：记得/回忆/告诉/讲/说等元请求动词
- 相对时间控制词：今天、昨天、最近、上周等（原句仍交给向量路）
- 泛泛身体部位：手、脸、脚（除非跟健康相关）
- 助词：的、了、着、过、是、在等

【输出要求】
- 最多 6 个词，空格分隔
- 按重要性排序（最重要的放前面）
- 只输出关键词，不要任何解释或标点

【示例】
- “亲爱的你还记得林小满是谁吗” → 林小满
- “宝贝，我吃了你，给我讲个故事吧，我喜欢什么类型的，你知道吗” → 故事 类型 喜欢 偏好
- “我们的婚礼是哪天” → 婚礼
- “我肚子不舒服，月经来了” → 月经 肚子不舒服
- “我今天好难过，想起了萤火计划” → 萤火计划 难过
